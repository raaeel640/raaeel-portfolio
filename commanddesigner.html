02 — SOFTWARE ENGINEERING PROJECT

CommandDesigner

A software engineering project focused on structured command management using client-server architecture and established design patterns.

Java Client-Server MVC DAO

OVERVIEW

Applying software engineering principles.

CommandDesigner was developed as a software engineering project to explore structured application architecture. The project uses a client-server approach and separates responsibilities through established design patterns.

MY WORK

What I implemented

Client-Server Architecture

Structured communication between the client and server components of the application.

MVC Pattern

Separated application responsibilities into model, view, and controller components.

DAO Pattern

Used the Data Access Object approach to separate data access logic from other components.

Project Structure

Organized the application into clear components to make the system easier to maintain.

PROJECT SCREENSHOT

CommandDesigner in development.

WHAT I LEARNED

Thinking beyond individual features.

This project helped me understand how architectural decisions and design patterns can make a software system more organized, maintainable, and easier to extend.
