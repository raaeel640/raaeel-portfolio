01 — BACKEND PROJECT

CRUD REST API

A backend REST API for managing tasks with persistent database storage and documented endpoints.

Node.js Express.js SQLite Swagger

OVERVIEW

Building a structured backend API.

This project was developed to understand how a REST API handles common CRUD operations. The application provides endpoints for creating, reading, updating, and deleting tasks while storing data persistently in a SQLite database.

MY WORK

What I implemented

API Endpoints

Implemented RESTful endpoints for managing task resources using Express.js.

Database

Replaced temporary in-memory storage with SQLite for persistent task data.

Documentation

Added Swagger/OpenAPI documentation so the API endpoints can be explored and tested.

Testing

Tested API requests and responses to verify that CRUD operations work correctly.

PROJECT SCREENSHOT

API documentation and testing.

WHAT I LEARNED

From routes to persistent data.

This project helped me understand how backend routes, HTTP methods, database operations, and API documentation work together to create a usable REST API.
